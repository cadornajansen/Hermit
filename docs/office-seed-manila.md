## Barangays and map locations

`lib/manila-barangays.json` contains all **897 Manila barangay names, PSGC codes and districts** from the [Philippine Statistics Authority PSGC](https://psa.gov.ph/classification/psgc/summary) and its Manila district pages. The finder accepts an exact barangay number or name and shows its district for business-clearance searches. The PSA data identifies jurisdictions; it supplies **no hall address or entrance coordinate**. The finder therefore offers only an explicitly unverified Google Maps text search for a separate barangay hall. That result is never promoted to an eligible office. For the Manila business permit flow, Ordinance 8754 supports the Bureau of Permits as the integrated intake point.

All source-listed physical addresses can be opened through a [Google Maps Search URL](https://developers.google.com/maps/documentation/urls/guide#search-action) using a user click. A search match is not a verified point. **No government seed has a saved coordinate, map pin, distance, or directions link.** The current office map can plot only independently reviewed coordinates. The records must be checked with each agency for public counter, hours, relocation, and current service rules before a production rollout.
Historical Taguig and generic hall guidance is suppressed for Manila office searches so it cannot override the integrated Manila clearance route.

## Local synthetic fixtures

`lib/office-demo.ts` contains two **invented permit counters and coordinates** to exercise map selection and distance display. They join the government list only when `OFFICE_FINDER_DEMO=true` in a **development** run. A production build ignores this setting. Their addresses and points are not real office data. The website UI does not display a demo badge; this documentation is the disclosure for local testers. The synthetic rows have no external directions, address-search, evidence, official-site, or eReport actions. Keep the setting off for user testing that could be mistaken for authoritative office guidance.

No live Google calls, billing changes, keys, cloud resources, or provider-derived office coordinates were added by this seed. Google map loading and address geocoding remain controlled separately by `OFFICE_FINDER_ENABLED`.
